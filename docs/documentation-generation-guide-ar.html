1. ⭐ القاعدة الحاكمة

⭐ Markdown هو المصدر الرسمي الوحيد.

⛔ وHTML نسخة مولَّدة — لا تُعدَّل يدويًا أبدًا.

#القاعدة
1⭐ كل معلومة في HTML لها أصل في Markdown — ⛔ ولا معلومة مضافة في HTML
2⛔ لا يُفتح HTML للتعديل إطلاقًا — التعديل في Markdown ثم إعادة التوليد
3⭐ الإصدار وتاريخ التوليد ظاهران في ترويسة الصفحة — فأي تأخر يُكتشف بالنظر
4⛔ لا CDN ولا إنترنت ولا Framework كبير ولا Backend — ملف واحد يعمل بلا شبكة
5⭐ المولّد بلا اعتماديات خارجية — مكتبة Python القياسية فقط

3.1.1 ⭐ وثيقة تصميم قاعدة البيانات — أمران بالترتيب

مقتطف
cd docs
python3 generate-erd.py  database-design-ar.md                          ← أولًا: الرسم
python3 generate-html.py database-design-ar.md database-design-ar.html  ← ثانيًا: الصفحة

⭐ الترتيب ملزم: الصفحة تدمج الرسم الموجود على القرص. وتوليد الصفحة وحدها بعد تعديل المخطط يعرض المصدر النصي بدل الرسم — ⛔ ولا يكسر شيئًا لكنه لا يُحدِّث الصورة.

البندالقيمة
متطلب generate-erd.py⭐ Graphviz (الأمر dot) — apt install graphviz · brew install graphviz · choco install graphviz
⭐ متى يُطلبوقت التوليد فقط — ⛔ والصفحة الناتجة لا تحتاج شيئًا: الـSVG مدموج داخلها
إن لم يكن مثبَّتًا⭐ يتوقف برسالة واضحة ⛔ ولا يحذف أي رسم سابق — فتبقى الصفحة سليمة
كيف يعرف المولّد أي رسم لأي مخطط⭐ ببصمة نص المخطط نفسه في erd-render-map.json — فتعديل المخطط يُبطل الرسم القديم تلقائيًا ولا تُعرض صورة قديمة خطأً
