# Patch توثيقي — الإصدار 1.1.3

**الإصدار:** 1.1.3 · **التاريخ:** 2026-09-17
**النوع:** **تصحيح علاقات + تثبيت دورة تسجيل المصروف**
**الأولوية:** **هذا المستند أعلى مستندات المشروع أولويةً.** عند أي اختلاف مع أي مستند آخر يُعمَل بما هنا.
**الحالة:** **توثيق فقط — لا كود ولا SQL ولا DDL ولا Migrations ولا تصميم فيزيائي.**
**مصدر القرار:** **قرارات تشغيلية معتمدة من صاحب المشروع** — لا اكتشاف من ملفات Excel أو العقود.

---

## 1. التصحيح الجوهري

### ❌ ما كان خطأً

- توثيق يعامل **الموقع** كأنه كيان مستقل تتفرع منه العمليات.
- **العملية وأمر الإسناد اختياريان في المسودة الميدانية**، ويحددهما المراجع لاحقًا.

### ✅ ما هو صحيح

> **العملية هي الكيان الأكبر، والمواقع توجد داخلها.**

```
الشركة → العملية → أمر الإسناد الخاص بالعملية → المواقع التابعة → المهندسون المكلفون → المصروفات
```
